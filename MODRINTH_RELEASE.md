# EVATEX-Background 1.8.6 — Adaptive shortcuts and optional Astral home

The Backgrounds shortcut now chooses a clear location using visible menu controls. It follows late-added buttons, hidden controls, window resizing and GUI scaling, and becomes compact when space is limited. Dense menus can use a slim vertical side shortcut with rotated text. Normal Minecraft prefers the lower centre; the existing Atlas 3.0.3 shortcut remains lower right.

Native title subclasses and recognized custom main-menu screens receive the shortcut through the shared screen lifecycle. Public custom-widget bounds are supported without linking client classes. Fully custom renderers that expose no bounds or bypass native widget drawing are not universally supported. Lunar users may need its Vanilla Overlay.

An optional black-and-white Astral home is now included. It uses large game tiles, a profile card, native options and original EVATEX background controls. Extra title actions are retained with footer pagination. **EVATEX main menu is disabled by default**; enable it in EVATEX settings and disable it to restore the installed client's title. No Atlas code or assets are bundled.

## Development note: the night of EVATEX 1.8.6

On 12 October 2026, after 2 a.m. in Türkiye, EVATEX-Background developer **EverVerity** shaped two ideas with Codex: a shortcut that finds clear space without spoiling the menu, and an optional black-and-white Astral home that stays off by default. Before going to sleep, he left one priority: keep it aesthetic. This small note records the care behind the release.

EverVerity, Codex ile estetiği koruyarak boş alana yerleşen akıllı butonu ve varsayılanı kapalı özel Astral menüyü şekillendirdi. Uyumaya gitmeden önce bıraktığı öncelik basitti: güzel görünsün, oyuncu isterse açsın. Bu not, o gecenin ve oyuncuya verilen özenin kaydıdır.
